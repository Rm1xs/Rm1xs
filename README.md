## 👋 About me

I'm a **senior Flutter developer with 4+ years of experience** creating high-quality, user-centric mobile apps for **iOS and Android**. I design and build scalable, efficient and visually compelling products that solve real problems, without compromising performance or reliability.

- 🔭 Currently working on **Sheriff World**
- 🧩 I care about clean architecture, thoughtful UX, motion and edge cases (offline, errors, slow networks)
- 📱 Native when it matters: WidgetKit / SwiftUI and Android App Widgets next to Flutter

### 🔆 [LightLine](https://github.com/Rm1xs/lightline_app)
Power-outage schedules for Ukraine (DTEK / Yasno): live status, an interactive day timeline, a planner that finds the best window for laundry or cooking, reminders, and home-screen widgets.

- **Widgets:** SwiftUI / WidgetKit (iOS) and Kotlin AppWidget (Android)
- **Push relay:** Cloudflare Workers + Firestore + FCM

- **Privacy-first:** no accounts, addresses never leave the device
